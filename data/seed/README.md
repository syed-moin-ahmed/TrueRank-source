# SYNTHETIC DEMO DATA — NOT THE RESEARCH DATASET

`demo_workers.csv` is generated by `scripts/generate_demo_dataset.py` (fixed random seed, 600 rows).
It uses the same column names as the research dataset so the application can be demonstrated
before the real 1,500-profile dataset is imported. Names, reviews and numbers are invented.
Every profile imported from this file is stored with `source = demo_seed` and shown with a "Demo data" badge.
